2.1.2 Micro Interruttore
=============================

Introduzione
-----------------------

In questo progetto, impareremo come utilizzare un Micro Interruttore. Un Micro Interruttore è un piccolo e molto sensibile interruttore che richiede una compressione minima per attivarsi. Poiché sono affidabili e sensibili, i micro interruttori vengono spesso utilizzati come dispositivi di sicurezza.

Sono utilizzati per evitare che le porte si chiudano se qualcosa o qualcuno è di mezzo e in altre applicazioni simili.

Schema Elettrico
--------------------

Collega il pin sinistro del Micro Interruttore al GPIO17 e due LED 
rispettivamente ai pin GPIO22 e GPIO27. Poi, quando premi e rilasci 
il braccio mobile del Micro Interruttore, vedrai i due LED accendersi 
alternativamente.

**Code**

.. note::

    Puoi **Modificare/Resettare/Copiare/Eseguire/Fermare** il codice qui sotto. Ma prima, devi andare nella directory del codice come ``raphael-kit/python-pi5``. Dopo aver modificato il codice, puoi eseguirlo direttamente per vedere l'effetto.


.. raw:: html

    <run></run>

.. code-block:: python

    #!/usr/bin/env python3

    from gpiozero import LED, Button
    from time import sleep

    # Inizializza il micro interruttore (LOW quando premuto)
    micro_switch = Button(17, pull_up=None, active_state=False, bounce_time=0.05)

    # Inizializza i LED
    red_led = LED(22)
    yellow_led = LED(27)

    try:
        while True:
            if micro_switch.is_pressed:
                print("YELLOW LED ON")
                red_led.off()
                yellow_led.on()
            else:
                print("RED LED ON")
                red_led.on()
                yellow_led.off()

            sleep(0.1)

    except KeyboardInterrupt:
        # Spegni entrambi i LED
        red_led.off()
        yellow_led.off()

**Spiegazione del Codice**

#. Importa le classi ``LED`` e ``Button`` da ``gpiozero`` per controllare i dispositivi GPIO, e ``sleep`` da ``time`` per i ritardi.

   .. code-block:: python

    from gpiozero import LED, Button
    from time import sleep

#. Crea un oggetto ``Button`` per il micro interruttore sul GPIO17.

   * ``pull_up=None`` disabilita la resistenza pull-up/pull-down interna in modo che il livello del pin sia determinato solo dal circuito, e ``active_state=False`` fa sì che ``is_pressed`` riporti ``True`` quando il pin legge LOW — che è ciò che accade quando il braccio viene premuto in questo circuito. ``bounce_time=0.05`` aggiunge un anti-rimbalzo di 50 ms per filtrare il rimbalzo meccanico del contatto. Vengono poi creati due LED: il LED rosso sul GPIO22 e il LED giallo sul GPIO27.

   .. code-block:: python

    # Inizializza il micro interruttore (LOW quando premuto)
    micro_switch = Button(17, pull_up=None, active_state=False, bounce_time=0.05)
    # Inizializza i LED
    red_led = LED(22)
    yellow_led = LED(27)

#. Nel ciclo principale, lo stato del micro interruttore viene controllato ogni 0,1 secondi. Mentre è premuto, il LED giallo si accende e il LED rosso si spegne; quando viene rilasciato, il LED rosso si accende e il LED giallo si spegne. Quando viene premuto Ctrl+C, ``KeyboardInterrupt`` viene catturato ed entrambi i LED vengono spenti prima che lo script termini.

   .. code-block:: python

    try:
        while True:
            if micro_switch.is_pressed:
                print("YELLOW LED ON")
                red_led.off()
                yellow_led.on()
            else:
                print("RED LED ON")
                red_led.on()
                yellow_led.off()
            sleep(0.1)

    except KeyboardInterrupt:
        # Spegni entrambi i LED
        red_led.off()
        yellow_led.off()
